# 🧠 Miniguia de Estudos: Machine Learning na Saúde e Previsão de AVC

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO,
utilizando o NotebookLM como ferramenta de aprendizagem ativa para
pesquisa, análise crítica e organização de conhecimento.

O tema escolhido foi a aplicação de Inteligência Artificial e
Machine Learning na área da saúde, com foco em modelos preditivos,
Ensemble Learning e previsão de Acidente Vascular Cerebral (AVC).

O projeto busca compreender não apenas o funcionamento dos modelos,
mas também suas limitações, métricas de avaliação, problemas de
desbalanceamento, validação, generalização e desafios para aplicação
clínica.

## 🎯 Objetivos

- Compreender os fundamentos de IA aplicada à saúde;
- Estudar Machine Learning e modelos preditivos;
- Analisar aplicações de ML na previsão de AVC;
- Compreender Ensemble Learning;
- Investigar o impacto de dados desbalanceados;
- Comparar métricas de avaliação;
- Compreender problemas de validação e generalização;
- Analisar limitações e desafios da IA na prática clínica;
- Utilizar o NotebookLM como ferramenta de aprendizagem ativa.
